# Sparkloom Code Review

Use this skill for pre-merge or pre-release review.

## Review Priorities

1. Security and secret exposure.
2. Data integrity and billing accuracy.
3. Permission and authentication boundaries.
4. Production failure modes.
5. Missing tests for changed behavior.

## Output

Lead with findings ordered by severity. Include file paths and exact behavior. Keep summaries brief.
