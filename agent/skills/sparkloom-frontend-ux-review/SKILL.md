# Sparkloom Frontend UX Review

Use this skill for UI and UX review.

## Checklist

1. Primary workflow is visible without instruction text overload.
2. Layout does not overlap on desktop or mobile.
3. Important actions have clear state: idle, loading, success, error, disabled.
4. Text fits its container.
5. Icons are familiar and tooltips exist where needed.
6. Color contrast is acceptable.

## Output

List blocking UX issues first, then polish opportunities.
