# Sparkloom Git Summary

Use this skill when summarizing changes for commit, release, or handoff.

## Workflow

1. Inspect changed files.
2. Group changes by user-visible behavior.
3. Mention migrations, environment variables, and operational steps.
4. Include tests that were run.

## Output

Provide a concise commit subject, body bullets, and release note bullets.
